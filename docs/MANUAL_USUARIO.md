# Manual de usuario resumido

1. Iniciar sesión o registrarse.
2. Desde Inicio seleccionar “Crear reporte georreferenciado”.
3. Completar título, descripción, categoría y severidad.
4. Pulsar “Usar mi ubicación GPS” o tocar el mapa.
5. Verificar el contexto climático.
6. Adjuntar una fotografía si corresponde.
7. Publicar.
8. Consultar Reportes o Mapa.
9. Abrir detalle para editar/eliminar si se tienen permisos.
10. Ajustar tema y densidad de tarjetas en Ajustes.
